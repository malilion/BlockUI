# Welcome to Block UI

Block UI is a block/pixel/crafting game-style React component library.

## Quick start

```bash
npm install @block-ui/react @block-ui/tokens @block-ui/themes
```

## Import

```jsx
import { BlockButton } from '@block-ui/react';
import '@block-ui/react/styles.css';
```

## Features
- 30+ components
- 5 themes
- 50+ pixel icons
- Full keyboard and accessibility support
