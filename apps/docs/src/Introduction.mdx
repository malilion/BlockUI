# Block UI

A **block × pixel × crafting** game-style component library for **React** and **TypeScript**.
Every main interaction is a block: bevelled buttons that snap up and press down, real keyboard-navigable
inventory grids, hearts for health and a crafting table that turns a grid into a result.

## Play the demo game

**[Block Miner](https://malilion.github.io/BlockUI/game/)** is a small mining and crafting game built only from the
published npm packages — dig through five themed layers, craft tools in `RecipeBook`, smelt ore in `Furnace`, trade
with `TradingUI` and fight monsters shown in a `BossBar`. It runs in Traditional Chinese through `zhTWMessages`.

## Install

```bash
pnpm add @malilion/block-ui-react
```

`@malilion/block-ui-react` installs `@malilion/block-ui-tokens`, `@malilion/block-ui-themes` and `@malilion/block-ui-icons`. React 18.2 and 19 are supported.

## Use

```tsx
import "@malilion/block-ui-react/styles.css";
import { BlockUIProvider, BlockButton, InventoryGrid, InventorySlot, ItemStack } from "@malilion/block-ui-react";
import { DiamondIcon } from "@malilion/block-ui-icons";

<BlockUIProvider theme="deepslate">
  <InventoryGrid columns={9}>
    <InventorySlot>
      <ItemStack icon={<DiamondIcon />} amount={12} name="Diamond" />
    </InventorySlot>
  </InventoryGrid>
  <BlockButton variant="grass">Start</BlockButton>
</BlockUIProvider>;
```

Optional: `pnpm add @fontsource/silkscreen` and import `@fontsource/silkscreen/400.css` + `700.css` for the pixel display font.

## What's inside

- **50+ components** — actions, forms, inventory, crafting, HUD, cards, data display, feedback, navigation and layout
- **5 themes** — grassland, cave, deepslate, nether, end (use the **Theme** button in the toolbar)
- **50+ original pixel icons** in `@malilion/block-ui-icons`
- **Localization** — every built-in string comes from `BlockUIProvider messages`; Traditional Chinese ships as `zhTWMessages` (use the **Language** button in the toolbar)
- **Accessible** — WCAG 2.2 AA; every story's interaction test and axe check run in CI in all five themes

## How these docs are organised

- **Foundations** — colors, typography, spacing, shadows & motion, themes, localization and icons, generated from the tokens
- **Components** — every component has `Default`, `Variants`, `States`, `Sizes`, `Disabled`, `Interactive` and `Responsive` stories, plus usage, props and accessibility notes
- **Patterns** — full screens built from the components: dashboard, player profile, inventory, crafting and server browser
